Motrix is a clean, full-featured desktop download manager powered by a bundled aria2 engine. It runs on macOS, Windows, and Linux as a native desktop app — and also as a headless server in Docker for NAS and home-server deployments. Browser extensions, a CLI client, and an open JSON-RPC protocol make it easy to integrate Motrix into any workflow.

## Why Motrix?

Motrix combines a polished desktop experience with powerful extensibility. The same download core runs in both the desktop app and a Docker container, so you can control downloads the same way from the UI, the CLI, a browser extension, or your own scripts.
